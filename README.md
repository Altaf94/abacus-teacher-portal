# Abacus Teacher Portal

React front-end for teachers on the abacus learning platform.

## Context

Uses the Abacus Learning API (Django REST Framework).

## Features

- Teacher pages for students and assignments
- State with Redux Toolkit; forms with React Hook Form and Zod

## Tech stack

- **Frontend:** React, Redux Toolkit, Tailwind CSS, React Query, axios

## Getting started

```bash
yarn install
yarn dev
```
